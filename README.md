# Sentinel Market — Historical Cloud Edition V1.1

Versione cloud della demo storica di Sentinel Market.

## Sicurezza
- Solo dati pubblici di mercato.
- Nessuna API key.
- Nessun username/password di exchange.
- Nessun trading reale.
- Modalità bloccata su HISTORICAL.

## Avvio su Streamlit Community Cloud
1. Crea o usa un account GitHub.
2. Crea un nuovo repository (può essere privato se concedi a Streamlit l'accesso richiesto).
3. Carica **tutti i file di questa cartella** nella root del repository.
4. Accedi a Streamlit Community Cloud.
5. Scegli **Create app** e collega il repository.
6. Come file principale seleziona `streamlit_app.py`.
7. Premi **Deploy**.
8. Otterrai un indirizzo `*.streamlit.app` apribile anche dallo smartphone.

## Funzioni V1.1
- Historical Replay su BTC/USDT ed ETH/USDT.
- Sentinel Score.
- Successo storico comparabile (quando il campione è sufficiente).
- Extreme Risk Index.
- Risk sizing in euro.
- Backtest e metriche di performance.
- Capitale simulato e versamento mensile configurabile nel pannello.

## Nota
Questa è una piattaforma di ricerca e validazione. I risultati storici non garantiscono risultati futuri.
